# Anexo - "Frameworks y Node JS"

JavaScript es uno de los lenguajes más populares en el desarrollo web actual. Cuenta con una amplia variedad de frameworks y herramientas que facilitan la creación de aplicaciones modernas, tanto en el navegador como en el servidor.

Un framework consiste en un conjunto de librerías y utilidades que proporcionan una estructura base para construir aplicaciones. Esto ayuda a simplificar tareas comunes, acelerando el desarrollo y permitiendo que los programadores se enfoquen en los aspectos específicos de cada proyecto.


## Frameworks y herramientas principales para JavaScript

### Frontend

- **React.js**: Biblioteca creada por Facebook que permite construir interfaces interactivas. Es muy utilizada en el desarrollo frontend.
- **Angular**: Framework completo mantenido por Google, ideal para desarrollar aplicaciones web tipo SPA (Single Page Application).
- **Vue.js**: Framework progresivo para crear interfaces de usuario, reconocido por ser más ligero y sencillo de aprender comparado con Angular y React.

### Backend y herramientas

- **Node.js**: Plataforma para ejecutar código JavaScript en el servidor.
- **Express.js**: Framework minimalista y muy flexible para crear aplicaciones web con Node.js.
- **MongoDB**: Base de datos NoSQL orientada a documentos, popular en proyectos JavaScript.

## ¿Qué es el Stack MERN?

El stack **MERN** es un conjunto de tecnologías JavaScript para desarrollar aplicaciones web de principio a fin (full stack). Está compuesto por:

- **M**: MongoDB – base de datos NoSQL
- **E**: Express.js – framework backend
- **R**: React.js – librería frontend
- **N**: Node.js – entorno de ejecución

## ¿Qué es el Stack MEAN?

El stack **MEAN** también es un conjunto de tecnologías full stack en JavaScript, pero utiliza Angular en lugar de React para el frontend:

- **M**: MongoDB
- **E**: Express.js
- **A**: Angular – framework para el frontend
- **N**: Node.js

## MERN vs MEAN

| Característica        | MERN                             | MEAN                          |
|-----------------------|----------------------------------|-------------------------------|
| Frontend              | React.js                         | Angular                       |
| Curva de aprendizaje  | Más sencilla (React es más liviano) | Más pronunciada (Angular es completo) |
| Flexibilidad          | Alta (React permite más libertad) | Menor (Angular impone estructura) |
| Escalabilidad         | Buena                            | Excelente para proyectos grandes |
| Comunidad             | Muy amplia y activa                     | También muy activa            |
